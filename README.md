# Rick & Morty Encyclopedia

A React + TypeScript + Vite app that consumes the public [Rick and Morty API](https://rickandmortyapi.com/) to browse characters, episodes, and locations from the show.

## Stack

- React 18 + TypeScript
- Vite
- ESLint

## Features

- Character browser backed by live API data
- Episode and location lookups via dedicated API service modules

## Run locally

```bash
npm install
npm run dev
```
